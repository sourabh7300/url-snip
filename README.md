# ✂️ snip

> Long links, snipped short. No account, no server, no nonsense.

**🔴 Live demo:** https://sourabh7300.github.io/url-snip/

## What it does
- Paste a URL, get a short code instantly
- Custom short codes when you want a say
- Optional redirect flow built in
- Proof that useful tools don't need a backend

## Built with
HTML · CSS · JavaScript — **zero frameworks**, single file, runs in any browser.
